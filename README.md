# Escáner de Alimentos

App web para escanear el código de barras de un alimento y ver su Nutri-Score, su grupo NOVA, sus alérgenos, sus ingredientes y su información nutricional.

- Datos: [Open Food Facts](https://world.openfoodfacts.org) (licencia ODbL)
- Lector de códigos: [html5-qrcode](https://github.com/mebjas/html5-qrcode) (licencia Apache 2.0)
- Se puede instalar en el celular (PWA) y tiene modo claro y oscuro.

App publicada: https://opesoc2013-art.github.io/escaneralimentos/
